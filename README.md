# 画面よみあげ

スマホ・タブレット・PCの画面に映っている文字を読み取り、音声で読み上げるWebアプリです。
アプリストアを通さず、ブラウザで開くだけで使えます。ホーム画面に追加すれば普通のアプリと同じように起動できます。

## できること

| 取り込み方法 | iPhone / iPad | Mac / Windows |
| --- | --- | --- |
| いまの画面を取り込む（画面共有） | × | ○ |
| スクリーンショット・写真を選ぶ | ○ | ○ |
| 画像や文字を貼り付け | ○ | ○ |

1. 画像を取り込むと、日本語と英語の文字を自動で読み取ります（OCR）。
2. 読みたい部分だけを指やマウスで囲むこともできます。
3. 読み上げ中は、いま読んでいる文に色が付きます。文をタップするとそこから読み直します。
4. 声の種類・速さ・高さを変えられます。設定は次回も残ります。

画像と文章は端末の中だけで処理します。外部のサーバーには送りません。
初回だけ、文字認識用のデータ（合計約8MB）をインターネットから取得します。

## 公開のしかた（GitHub Pages）

1. GitHub でこのリポジトリを開き、**Settings → Pages** を選ぶ
2. 「Source」を **Deploy from a branch** にし、ブランチ（例: `main`）と `/ (root)` を選んで保存
3. 数分後に `https://<ユーザー名>.github.io/voiceover/` で開けるようになる

## iPhone / iPad での使い方

1. Safari で上のURLを開き、共有ボタン →「ホーム画面に追加」
2. 読みたい画面でスクリーンショットを撮る（サイドボタン＋音量を上げるボタン）
3. アプリを開いて「画像・スクショを選ぶ」→ 撮った画像を選ぶ →「文字を読み取る」

iOS の制約で、Webアプリからほかのアプリの画面を直接見ることはできません。そのためスクリーンショットを経由します。

> 参考：iPhone / iPad には標準機能の「画面の読み上げ」もあります。
> 設定 → アクセシビリティ → 読み上げコンテンツ →「画面の読み上げ」をオンにすると、
> 画面上端から2本指で下にスワイプするだけで、表示中の文章を読み上げます（Safari やメールなど、文字が画像になっていない画面向け）。
> このアプリは、画像になった文字や、標準機能で読めない画面を読むときに使います。

## Mac / PC での使い方

「いまの画面を取り込む」を押し、読みたいウィンドウや画面を選ぶと、その瞬間の画面を取り込みます。
あとは囲み →「文字を読み取る」で読み上げます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の部品 |
| `style.css` | 見た目（ダークモード対応） |
| `app.js` | 取り込み・文字認識・読み上げの処理 |
| `sw.js` | オフラインでも開けるようにする仕組み |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | ホーム画面に追加したときの名前とアイコン |

文字認識には [Tesseract.js](https://github.com/naptha/tesseract.js)、読み上げにはブラウザ標準の Web Speech API を使っています。
